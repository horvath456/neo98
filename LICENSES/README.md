# License texts

This folder holds the license texts of the third-party code Neo98 uses, one
file per project. [THIRD_PARTY.md](../THIRD_PARTY.md) says what each project
is used for. The `*-source-notices.txt` files collect the copyright headers of
the individual source files in Unicorn, DOSBox Pure and musl.

`GPL-3.0.txt` applies to Linux packages that include shaderc; see
[THIRD_PARTY.md](../THIRD_PARTY.md) for why.

`LicenseRef-Microsoft.txt` is not a license; it explains a marker that some
development tools put on files they generate from a local Windows
installation.
